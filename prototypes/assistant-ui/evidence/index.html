    Inspired by

    The public sites this direction borrows from, and the one pattern taken from each.

    • Perplexity (opens in a new tab) perplexity.ai

      Citation pattern: a row of source cards above the answer, and numbered inline citations that point back to them.

    • Vercel Docs (opens in a new tab) vercel.com/docs

      Layout and type scale: the docs “ask AI” panel, a monochrome interface with a single accent colour and a tight, precise type scale.

    • Stripe Docs (opens in a new tab) docs.stripe.com

      Status callouts: tinted note, warning and error boxes with an icon and a bold label, and a clear heading hierarchy.

    Patterns only — no logos, brand names in the UI, copy or paid fonts were taken.
