Or start with one of these

    Every answer reads like a brief

    1. I

      Bottom line

      The short answer, first, in two or three sentences.

    2. II

      Key points

      The issues that matter, one per line.

    3. III

      Notes

      Every document it drew on, numbered and linked, so you can check it.

    Inspired by

    This direction borrows patterns from three sites known for careful, readable publishing.

    • Anthropic — Newsanthropic.com/news

      Editorial whitespace, serif-led headlines and quiet, low-chrome controls.

    • Stanford HAI — Policyhai.stanford.edu/policy

      Policy-brief framing: a summary first, then the key points beneath it.

    • Our World in Data — Artificial Intelligenceourworldindata.org/artificial-intelligence

      Numbered notes and plain source provenance: say where each link goes and what was not cited.

    Patterns only — no logos, brand names in the UI, copy or paid fonts were taken.
